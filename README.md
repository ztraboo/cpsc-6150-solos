# cpsc-6150-solos
Details solo projects for the CPSC 6150 class about `Horoscopes`.

## How to use these files
Each CPSC 6150 assignment in the course has its own branch in this repository. To see the code for that assignment, choose the appropriate branch. For example, to see the code for assignment `Solo 1 – Multiple Screens with Navigation`, checkout the `assignment-solo-1` branch.

**Important**: If you are cloning the repo to your desktop, you will need to perform a `packages get` / `pub get` to install any dependencies that the project may have at that point in the course.
